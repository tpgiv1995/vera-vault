# raw/audio-transcripts/

Older local meeting recordings transcribed to markdown (e.g. a loopback-audio + Whisper tool).
Largely superseded by `meeting-assistant/`, kept for historical recordings.

- **Source:** manual / legacy local recorder.
- **Naming:** `YYYY-MM-DD HHmm - Title.md`

**Sensitivity caveat:** like `meeting-assistant/`, these often capture sensitive 1-on-1s or
solo thinking-out-loud. Use the meeting-transcript-depth heuristic: read fully for sensitive or
contentious content, use a structured-sections approach for routine meetings. Never quote
sensitive material verbatim; paraphrase and flag anything unclear in `wiki/inbox.md`.
