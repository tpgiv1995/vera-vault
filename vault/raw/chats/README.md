# raw/chats/

Markdown exports of 1-on-1 and group chat threads (e.g. team chat or DM platforms).

- **Source:** manual exports / pipeline pull. Static snapshots, not continuously live.
- **Naming:** descriptive, e.g. `chat_jordan_sam_1on1.md` or `chat_project-x_team.md`.

Treat chats like email threads: extract decisions, action items, and substantive project
context. **Do not create per-chat wiki pages** - distribute the content across existing
project/people pages, and add the chat file path to the `sources:` frontmatter of every page it
informs. Skip informal banter (social, off-topic).
