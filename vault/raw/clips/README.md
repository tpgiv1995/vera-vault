# raw/clips/

Web articles and reference material you save for later.

- **Source:** manual (web clipper, copy-paste, downloads).
- **Naming:** descriptive slug, optionally date-prefixed.

During ingestion, Claude identifies which existing concept or project page each clip informs and
adds the clip as a `source:`. If a clip doesn't fit any existing page, it is logged to
`wiki/inbox.md` under "## Unmatched Clips" rather than spawning a new page. Clips are reference
material - they enrich pages, they don't usually become pages of their own.
