# raw/meeting-assistant/

Transcripts from a **local AI notetaker** that captures whatever is on your microphone and
auto-exports a markdown transcript here.

- **Source:** auto-exported by the local notetaker app (manual setup; not a cloud connector).
- **Naming:** `Title [8hex-id].md`
- **Frontmatter:** `type: meeting-transcript`, plus session id, speakers, and duration.

**Sensitivity caveat:** these capture casual, work, or personal audio - not just structured
meetings. Speaker labels are often generic ("Speaker 1"); attribute real names only when context
is unambiguous. Skip purely personal sessions when building wiki pages. Never quote sensitive
content verbatim - paraphrase neutrally.
