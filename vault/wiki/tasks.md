# Tasks

Your tasks live on the project and meeting pages where they came up. This page just collects them.
Claude never adds tasks here.

## My open tasks

Every unchecked task in the vault that mentions `[[me]]` (built-in Obsidian search, no plugin needed):

```query
task-todo:"[[me]]"
```

## Done

```query
task-done:"[[me]]"
```

> Want due-date views (overdue, due this week)? Install the community plugin **Tasks** and ask Claude
> to add the queries here. The task format the vault already uses is the Tasks plugin's format.
